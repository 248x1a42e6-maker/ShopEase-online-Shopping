# ShopEase – Online Shopping Website

A beginner-friendly front-end mini project built with HTML, CSS and JavaScript.

## Features
- Responsive shopping homepage
- Product listing, search and category filter
- Add to cart with quantity controls and total
- Wishlist
- Demo login and registration
- Demo checkout (no real payment)
- Cart, wishlist and demo user saved in browser localStorage

## How to run
1. Download and extract the project folder.
2. Open the folder.
3. Double-click `index.html`, or open it with VS Code and use Live Server.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Important note
This is a front-end demonstration project. It does not use a real database, secure authentication, payment gateway or order server. Do not enter real passwords or payment information.
